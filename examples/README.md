# Przykładowe pliki (bez danych osobowych)

* `kursy_przyklad.csv` – format pliku kursów dla `--rates-file`
  (`waluta;data;kurs`, `data` = data publikacji tabeli NBP, kurs = PLN za 1 jednostkę).
  Wartości pochodzą z kolumny „Invoice Level Exchange Rate" raportu Amazon i z arkusza
  próbnego klienta – służą tylko do demonstracji, **nie są oficjalnymi kursami NBP**.
